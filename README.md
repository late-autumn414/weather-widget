# 🌤️ 天气桌面小工具 — 多城市天气插件

> **一款支持多城市同屏显示的桌面天气小工具，轻松掌握各地天气动态**
> 适用于 Deepin / UOS / Linux 桌面环境，基于 Python + Tkinter 构建

---

## ✨ 功能特性

| 特性 | 说明 |
|------|------|
| 🏙️ **多城市同屏** | 同时显示多个城市的实时天气，支持搜索/添加/删除/排序 |
| 📅 **3天预报** | 每个城市展示未来3天天气趋势（温度、天气描述） |
| 🔍 **城市搜索** | 支持按拼音/汉字实时搜索城市，快速添加 |
| 🎨 **自定义背景** | 支持更换桌面背景图片，自动压暗处理 |
| 🌙 **深色主题** | 现代化深色 UI，护眼舒适 |
| 🔄 **自动刷新** | 每30分钟自动更新天气数据，支持数据缓存 |
| 📦 **断网保护** | 网络异常时自动显示缓存数据，并提示用户 |
| 🖱️ **自由拖拽** | 可随意拖动窗口到桌面任意位置，位置自动记忆 |
| 📋 **右键菜单** | 刷新、最小化、设置、更换背景等快捷操作 |
| ⌨️ **快捷键** | F5 刷新、Esc 最小化 |
| 💾 **配置保存** | 城市列表、背景图片、窗口位置自动保存，下次启动恢复 |

## 🚀 快速开始

### 环境要求

- **操作系统**: Deepin 20/23, UOS 20/25, 或其他 Linux 发行版
- **Python**: 3.8+
- **Tkinter**: 一般系统自带（如缺少，`sudo apt install python3-tk`）
- **Pillow**: 可选，用于背景图片支持（`pip3 install Pillow`）
- **网络**: 需要互联网连接获取天气数据

### deb 包安装（推荐）

```bash
# 构建 deb 包（需要 dpkg-deb，Debian 系发行版自带）
./packaging/build_deb.sh

# 安装（自动处理 python3 / python3-tk 依赖）
sudo apt install ./dist/weather-widget_2.0.0_all.deb

# 启动（应用菜单点击「天气小工具」，或命令行）
weather-widget

# 卸载
sudo apt remove weather-widget
```

### 一键安装

```bash
# 下载项目后，进入目录
cd weather-widget-submission-20260831

# 安装
chmod +x setup.sh
./setup.sh

# 启动（安装后双击桌面图标或运行）
python3 src/main.py
```

### 手动运行

```bash
# 安装依赖
pip3 install -r requirements.txt

# 直接运行
python3 src/main.py

# 或进入 src 目录运行
cd src && python3 main.py
```

### 卸载

```bash
./setup.sh uninstall
```

## 🎮 使用指南

### 基本操作

| 操作 | 方式 | 说明 |
|------|------|------|
| **移动窗口** | 左键拖拽 | 拖拽到桌面任意位置 |
| **右键菜单** | 右键点击 | 弹出快捷操作菜单 |
| **刷新天气** | 点击「🔄 刷新」/ F5 | 立即更新所有城市天气 |
| **最小化** | 点击「🗕」/ Esc | 最小化到任务栏 |
| **退出** | 右键 → 退出 | 关闭应用 |

### 管理城市

1. 右键 →「⚙ 设置城市」或点击底部「⚙ 设置」
2. 在对话框中：
   - **搜索城市**：在搜索框输入城市名（支持拼音），实时过滤
   - **添加城市**：从右侧列表中选中（可多选），点击「添加选中城市」
   - **快速添加**：搜索后直接按回车，快速添加第一个匹配城市
   - **手动输入**：输入自定义城市名（支持 "城市名, 显示名" 格式）
   - **删除城市**：左侧选中城市后点击「🗑 删除」
   - **排序**：使用 ↑ 上移 / ↓ 下移 调整顺序
3. 点击「保存并关闭」生效

### 更换背景

1. 右键 →「🎨 更换背景图」
2. 选择本地图片即可
3. 右键 →「↩ 恢复默认背景」可还原

## 🔧 技术架构

### 数据源

- 使用 [wttr.in](https://wttr.in) 免费天气 API（基于 Open-Meteo 数据）
- 请求格式：JSON（`?format=j1`）
- 包含：实时天气、体感温度、湿度、风速风向、能见度、UV指数、未来3天预报

### 核心技术

| 技术 | 用途 |
|------|------|
| **Tkinter** | GUI 桌面界面（Python 标准库） |
| **urllib** | 天气数据 HTTP 请求 |
| **多线程** | 并发获取多城市天气数据 |
| **数据缓存** | 10分钟缓存 + 断网保护 |
| **指数退避重试** | 网络请求失败自动重试 |
| **Pillow** | 背景图片缩放、亮度调节 |
| **JSON 配置** | 城市列表、背景路径、窗口位置持久化 |

### 设计模式

- **MVC 架构**：数据（Model）、UI（View）、控制（Controller）分离
- **观察者模式**：天气数据异步获取后自动回调渲染 UI
- **单例配置**：ConfigManager 统一管理应用配置

## 🌐 API 参考

### wttr.in API
```
GET https://wttr.in/{city}?format=j1
```

返回 JSON 格式，包含：
- `current_condition[0]`：当前天气（温度、体感、湿度、风速、天气描述、UV指数、能见度）
- `weather[0..2]`：未来3天预报（最高/最低温、每小时天气描述）

### 请求限制
- 免费使用，无需 API Key
- 建议合理控制请求频率（本工具默认30分钟刷新一次）

## 🔧 可复现构建说明

本项目使用标准 Python 工具链，可按以下步骤**从源码可复现构建**：

### 环境准备
```bash
# Python 3.8+（推荐 3.10+）
python3 --version

# 创建独立虚拟环境（推荐，避免污染系统环境）
python3 -m venv .venv
source .venv/bin/activate
```

### 安装锁定依赖
```bash
# requirements.txt 已锁定全部依赖版本，保证构建一致性
pip install --upgrade pip
pip install -r requirements.txt
```

### 运行与验证
```bash
# 语法检查（应无任何输出/错误）
python3 -m py_compile src/*.py

# 启动应用
python3 src/main.py

# 单元自检（验证天气 API 连通性）
python3 -c "from src.weather_api import get_weather_data; print(get_weather_data([('北京','北京')]))"
```

### 打包发布
```bash
# 一键安装（生成桌面快捷方式 + 开机自启）
chmod +x setup.sh && ./setup.sh install

# 构建 deb 包（产物输出到 dist/）
./packaging/build_deb.sh

# 构建前运行打包脚本单元测试
./packaging/test_build_deb.sh

# 自定义版本/维护者/输出目录
DEB_VERSION=2.0.0 DEB_MAINTAINER="Your Name <you@example.com>" \
    ./packaging/build_deb.sh -o /tmp/debs

# 可复现构建（固定时间戳，两次构建产物字节级一致）
SOURCE_DATE_EPOCH=1700000000 ./packaging/build_deb.sh

# 构建发布包
zip -r weather-widget-v2.0.0.zip . -x ".git/*" -x "*__pycache__*" -x "*.pyc"
```

### deb 包内容布局

| 安装路径 | 说明 |
|----------|------|
| `/usr/lib/weather-widget/` | 应用主体（src/ + assets/ + requirements.txt） |
| `/usr/bin/weather-widget` | 启动器命令 |
| `/usr/share/applications/weather-widget.desktop` | 应用菜单入口 |
| `/usr/share/icons/hicolor/` | 图标（PNG 128x128 + SVG） |
| `/usr/share/doc/weather-widget/` | copyright 与 changelog |

> 依赖声明：`Depends: python3 (>= 3.8), python3-tk`，`Recommends: python3-pil`（可选背景图支持），
> 由 apt 安装时自动处理；用户配置仍保存在 `~/.config/weather-widget/`，卸载不丢失。

> **可复现性说明**：`requirements.txt` 中所有依赖均以 `==` 锁定精确版本，
> 配合虚拟环境即可在任意 Linux 发行版上获得一致的构建结果。
